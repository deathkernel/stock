# API Sources

## Alpha Vantage
Broad market, technical, fundamentals, news/sentiment and economic endpoints.

## Twelve Data
Global time-series, technical indicators and fundamentals.

## Finnhub
Market data, financial statements, estimates, technical analysis and news/sentiment.

## SEC EDGAR
Official US filings and XBRL facts. No API key is required, but requests should identify the client with a User-Agent.

Keys belong only in .env. Never commit secrets.
